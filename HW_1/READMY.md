# Simple Math Testing Project

Этот проект представляет собой пример настройки среды тестирования на языке Python с использованием фреймворка pytest. В проекте реализован класс с базовыми математическими операциями и набор автоматизированных тестов для проверки их корректности.

## Структура проекта

- `simple_math.py` — файл с исходным кодом класса SimpleMath.
- `test_simple_math.py` — файл с тестами (unit tests).
- `.gitignore` — файл для исключения системных и временных папок из репозитория.

## Как запустить проект

Следуйте этим шагам, чтобы настроить окружение и запустить тесты на своем компьютере.

### 1. Создание виртуального окружения

Это создаст изолированную папку `venv` со своим интерпретатором Python.

```bash
python -m venv venv
```

### 2. Активация окружения

Этот шаг обязателен, чтобы терминал "увидел" установленные библиотеки.

**Для Windows (Git Bash / PowerShell):**

```bash
source venv/Scripts/activate
```

**Для macOS / Linux:**

```bash
source venv/bin/activate
```

После активации в начале строки терминала должно появиться `(venv)`.

### 3. Установка зависимостей

Установите фреймворк `pytest`, необходимый для запуска тестов:

```bash
pip install pytest
```

### 4. Запуск тестов

Вы можете запустить все тесты одной командой:

```bash
pytest test_simple_math.py
```

Если команда `pytest` не найдена (частая проблема в Windows), используйте запуск через модуль Python:

```bash
python -m pytest test_simple_math.py
```

## Описание тестов

В проекте проверяются следующие методы:

- `square(n)` — возведение числа в квадрат. Тестируются положительные, отрицательные числа и ноль.
- `cube(n)` — возведение числа в куб. Проверяется сохранение знака числа при возведении в третью степень.

## Технологии

- Python 3.x
- Pytest (фреймворк для тестирования)
